# Life Forge

I want to create a system to organize and track my life.

Focus strictly on:
- University (lectures, assignments, study hours)
- Software engineering & learning (Python, algorithms, problem solving, coding hours)
- Business & building real projects

Exclude:
- T-shirt brand and unrelated side distractions

Interface & Mechanics:
- Hybrid (SaaS + RPG): Clean, dark Linear-style dashboard with subtle XP bars, levels, and streak counters for motivation without visual clutter.
- Daily logging: Study hours, deep coding hours, time wasted (e.g. YouTube), priority tasks, and daily mood/focus rating.
- Visual charts: Productive vs. wasted time trends, skill level progression (Algorithms, Python, Uni), and consistency streaks.
- Calm and motivating: A high-leverage command center that shows whether I'm actually improving and where time is being lost.
